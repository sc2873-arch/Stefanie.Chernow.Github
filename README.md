## 🛠️ Local Development Setup

To run or push this project locally using Git, follow these commands:

```bash
# Initialize a local Git repository
git init

# Stage the index.html file
git add index.html

# Commit changes
git commit -m "Initial commit with index.html"

# Rename branch to main
git branch -M main

# Link to your remote GitHub repository
git remote add origin [https://github.com/schernow/Stefanie.Chernow.Github.git](https://github.com/schernow/Stefanie.Chernow.Github.git)

# Push code to GitHub
git push -u origin main
